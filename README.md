# m5stack-tab5-esp32-p4-rv32ima
[Very MIP] My fork of rv32ima linux emulator on M5Stack Tab5 (M5Tab5) ESP32-P4, based on Epiczhul/esp32p4-rv32ima and cnlohr/mini-rv32ima

## ESP-IDF version
* ESP-IDF 5.4
